# Biological timing grid, version 0.4

`clock_ns D` makes one integer tick represent exactly `D` simulated nanoseconds. It is a declared coordinate system, not wall-clock scheduling. `D` is between 1 and 1,000,000,000 inclusive. A `bio_*` duration must be divisible by `D`, must satisfy the existing tick capacity, and must appear after the clock declaration. Zero refractory time is valid. Positive edge delays are limited to 64 ticks; positive STDP windows to 4096 ticks; total duration to 1,000,000 ticks. Off-grid inputs are refused. A seeded `bio_noise` consumes exactly the existing entropy stream at the converted tick.

For a membrane relaxation time `tau_ns` in 1 to 1,000,000,000,000, the retention factor is the backward-Euler solution of the homogeneous leaky membrane equation: `a = tau_ns / (tau_ns + D)`. The integer factor is `round_nearest_even(65536 * a)`; a result of zero or 65536 is refused because it loses all decay or all integration at Q16 resolution. The existing C core then evaluates `reset + trunc((voltage - reset) * q / 65536) + input` with checked arithmetic. This is a deterministic implicit-Euler discretization, not the exact exponential propagator and not a claim of calibrated biological accuracy. New fractional retention quantizes once during parsing; legacy `neuron` values remain user supplied.

`bio_neuron`, `bio_edge`, `bio_stim`, `bio_noise`, and `duration_ns` convert to existing neuron, edge, stimulus, noise, and steps fields. A clock-enabled receipt declares `clock_ns`, includes `time_ns` on each tick, and expresses causal event time in integer nanoseconds. The scenario hash commits the original declaration bytes. Legacy scenarios omit these fields and produce their original receipts. Integer current and synaptic weights retain their original units and dynamics.

Example: [bio_clock.nm](../examples/bio_clock.nm). The grid concept follows publicly documented simulator clock semantics, while this project's numerical law and receipt format are its own; see [references](REFERENCES.md).
